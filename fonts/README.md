# Workout image fonts

Unmodified Anton Regular by Vernon Adams and Barlow Condensed Bold by Jeremy Tribby, bundled from the official Google Fonts repository. Both are SIL Open Font License 1.1; original copyright notices and license texts are included beside the fonts. See provenance.json for exact source URLs and SHA-256 hashes.

Fonts are used only to render workout images. Synthetic italic and layout transforms happen while drawing, without modifying the font files. The card texture is original deterministic procedural grain. No mockup bitmap or generated sample workout text is included in the app.
