# Reptide (iPhone beta)

A workout tracker you add to your iPhone Home Screen. Version 0.9.43.

## Install on iPhone
1. Open the app link in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open **Reptide** from your Home Screen.

Your workouts are saved only on your phone. Export a backup now and then from **Settings → Backup**.
Deleting the Home Screen icon deletes the workouts saved in it.

This folder is generated by `scripts/build-iphone.mjs`. Don't edit it by hand.
